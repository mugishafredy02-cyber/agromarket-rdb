# AgroMarket Rwanda MVP

This project is a minimal MVP for an agricultural marketplace focused on Rwanda farmers who are certified by the Rwanda Development Board (RDB).

## Features included

- Landing page for AgroMarket Rwanda
- Verified farmers section
- Product listing from certified sellers
- Farmer registration form with RDB certificate input
- Admin certificate verification mock endpoint
- Dashboard stats for marketplace overview
- Express server to serve the website and mock API

## Tech stack

- Node.js
- Express
- Static HTML, CSS, and JavaScript

## Run locally

1. Install dependencies:
   npm install
2. Start the app:
   npm start
3. Open in browser:
   http://localhost:3000

## Project idea

This MVP supports the following business idea:

- Only verified farmers can sell on the platform
- Buyers can compare verified suppliers
- Farmers submit an RDB certificate number during registration
- Admin validates the certification before the farmer becomes active
- Platform builds trust across districts in Rwanda
